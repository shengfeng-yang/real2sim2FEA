# real2sim2FEA
From Robot Task Data to Structural Load Spectra: A general method for turning a robot's recorded task data into load cases and cycle spectra for its own structure — then that method narrowed onto one bimanual ALOHA task, 557 episodes of it, and carried through to a solved upper-arm stress field.
https://shengfeng-yang.github.io/real2sim2FEA/
